1. Design overview
The program is a single-file console application where each menu option has its own function. Records are stored as dictionaries in a global list. A shared print_table() helper prints the aligned table for View All and Search.

Final mark is the average of the three assessment marks, and the grade uses the unit boundaries (HD 85+, DN 75-84, CR 65-74, PS 50-64, FL below 50). Highest, lowest and grade counts use ordinary for-loops, as the brief requires.

Recursion: recursive_sum totals the final marks for the class average. Recursion suits this small list. For very large lists (over about 1,000 students), Python's recursion limit would make a loop the better choice.

    FUNCTION recursive_sum(marks_list, index = 0)
        IF index >= length of marks_list THEN RETURN 0           // base case
        RETURN marks_list[index] + recursive_sum(marks_list, index + 1)   // recursive case
    END FUNCTION

2. File handling
Data is stored in data/students.csv. The program loads the file at start-up. If the file does not exist it creates a new one with the correct header and continues without crashing. On exit the current list is written back to the same file.

The file path is built from the location of gradebook.py, so the program works from any folder. If the data folder is missing, it is created automatically. Each CSV row is checked on its own, so an invalid row is skipped with a warning instead of stopping the whole load.

3. Input validation
Every input that can fail is checked in a loop:
- empty text is rejected
- non-numeric marks are rejected
- marks outside 0-100 are rejected
- "nan" is rejected as a mark
- duplicate student IDs are blocked when adding
- unknown IDs for update/delete show a clear message
- delete confirmation repeats until the user types Y or N

5. Defects found and fixed
1. Crash when the data folder was missing. The program used the path "data/students.csv", so it crashed with FileNotFoundError when the folder did not exist or when it was run from another folder. Fix: the path is now built from the script's own location using os.path, and the folder is created with os.makedirs(..., exist_ok=True).
2. One bad CSV row wiped all records. A single unreadable row made the whole load fail, and the empty list was then saved over the file on exit. Fix: each row is now checked on its own, and bad rows are skipped with a warning.
3. "nan" accepted as a mark. Python's float("nan") passed the 0-100 check. Fix: a check was added that rejects NaN.
4. Delete accepted any answer as "No". Fix: it now asks again until the user types Y or N.
5. Duplicate table-printing code in View All and Search. Fix: moved into one print_table() function.

Known limitation: if the CSV file is open in another program (e.g. Excel) when exiting, the save fails. The program shows an error and does not crash, but changes from that session are not saved.
